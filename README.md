# Theatre API

A REST API for a city theatre that allows browsing performances, selecting seats, and booking tickets online.

---

## Overview

This project is built with Django and Django REST Framework. It provides the following features:

- View information about actors, genres, plays, theatre halls, and performances.
- Make seat reservations and purchase tickets via the API.
- User registration, authentication, and booking management.

---

## Technology Stack

- Python 3.11+
- Django 4.x
- Django REST Framework
- Git, GitHub
